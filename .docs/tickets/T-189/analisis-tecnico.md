# Análisis técnico · T-189

La lista global de horizontes se rechaza si contiene alguna combinación imposible para las clases solicitadas. Cada autorización de presupuesto registra BAC, AC, EV, CPI y EAC con el avance de fases servidas y sus pesos presupuestados. Sin avance medible se declara EAC no disponible. R8 clasifica la incidencia con un vocabulario cerrado.

R02. Una lista de horizontes válida cambia P-03; cada celda prohibida queda en los rechazos y un valor vigente o ya programado no duplica CFG. El cálculo del valor ganado se comprueba con fases servidas y un coste conocido. Las AUT incluyen las UC autorizadas y el límite resultante. R8 etiqueta el hallazgo en el momento de la detección, también si el texto declarado es el nombre de un campo. Solo las etiquetas y los nombres seguros llegan a la incidencia.
