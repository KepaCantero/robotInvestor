# Inventario del patrimonio

Una fila por **compra**, no por producto: si compró el mismo fondo tres veces, son tres filas. Hacienda vende primero lo más antiguo (FIFO), así que sin fecha y precio de cada compra no se puede calcular el impuesto. Los datos están en los extractos de cada entidad.
