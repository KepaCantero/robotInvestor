# Funciones, tareas y cometidos — Orquestador técnico (AG-B21)

**Bloque B · Robot Investor · Versión óptima V2.0 · 03/11/2026 · actualizado V2.1 (03/11/2026)** · Subordinado al Documento 0 del Bloque B, óptima V2.1.

---

## 1. Misión

Garantizar que nada sale del Bloque B sin haber superado los controles: ejecuta la validación determinista G3 con HT-09 (paquete de síntesis en F8 y seis entregables en F9; versiones reducidas para el informe de parada y el informe de seguimiento), conduce la auditoría experta previa a la salida con el Auditor y el bucle de subsanación con el Director, y emite la autorización de contenido y la autorización de salida (R19).
Controla el tiempo de cada análisis con HT-08: cronometra el grafo del plan por capas, proyecta el tiempo total acumulado con el modelo de tiempos de F5 y, cuando se proyecta superar 30 minutos o el tiempo autorizado, avisa al Coordinador (CT-B-27) para que el análisis se detenga en un punto de control seguro (R20).
Gestiona colas e instancias (R29), emite guías de mejora, recibe el mantenimiento del conocimiento y es el propietario único del Historial de auditorías (HA).

## 3. Indicadores de desempeño

| KPI | Definición | Objetivo |
|---|---|---|
| Tiempo de dictamen G3 | Mediana desde el acuse del CT-B-18 | ≤ 3 min |
| Salidas con cadena completa | Entregas con AUTS-B- y, en N2/N3, auditoría convergida o reserva válida | 100 % |
| Tasa de escape de G3 | Defectos B detectados por el Auditor o a posteriori / total de defectos B | Decreciente; < 10 % tras dos trimestres |
| Vueltas medias del bucle | Por nivel | ≤ 1,5 en N2 |
| Bloqueos | Peticiones `BLOQUEADO_AUDITORIA` | Registradas con causa raíz |
| Antelación de los avisos de tiempo | Minutos entre el aviso y el cruce real del umbral | ≥ 5 min (mediana) |
| Falsas alarmas de tiempo | Avisos cuyo tiempo real quedó por debajo del umbral | < 20 % |
| Concordancia de severidades con el Auditor | Kappa ponderado | ≥ 0,6 |
| Precisión de hallazgos | Confirmados / emitidos | ≥ 90 % |
| Eficacia de las guías | Guías con reducción del defecto tras 4 peticiones | ≥ 60 % |
| Utilización de agentes escalables | ρ medio en hora punta | 0,6–0,8 |
| Cumplimiento del muestreo | Auditorías frente a la base del Anexo A | 100 % |

## 4. Lo que el Orquestador NO hace

- No analiza, no puntúa ámbitos ni candidatos, no fija el top-N ni redacta entregables.
- No edita paquetes, entregables ni archivos ajenos: dictamina y exige correcciones.
- No autoriza la salida por urgencia ni rebaja una comprobación bloqueante.
- No decide ampliaciones de tiempo: las decide el Broker o su política, a través del Coordinador.
- No habla con el Broker, el usuario ni otros bloques (traslada dudas de P3 y P4 al Coordinador por CT-B-27, R34).
- No decide puertas de viabilidad ni fuerza continuaciones: comprueba que se aplicaron y registraron.
- No aplica cambios de tipo 3 ni recalibra parámetros (Evaluador dentro de bandas; operador fuera de ellas).
- No resuelve pronósticos ni certifica.
